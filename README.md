# Light My Fire

Premium 1-on-1 SAT, GMAT & GRE preparation and admissions consulting website.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Before launch

Update `src/data/siteContent.js` with the real:
- booking URL
- Leland URL
- Google Reviews URL
- email
- phone

Replace the portrait placeholder in `AboutSameer.jsx` with the approved Sameer photograph when available, and add the official Light My Fire logo asset.

The homepage copy is intentionally kept in the components/data without AI-generated rewrites.
